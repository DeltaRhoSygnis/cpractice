# debugging

Diagnoses a failure by **testing the learner's hypotheses with observable
evidence** instead of guessing.

Separates expected behaviour, actual behaviour, reproduction, and evidence.
Asks for a hypothesis before suggesting causes, then chooses the next smallest
observation or experiment and reassesses. After resolution, classifies the root
cause and captures a prevention habit only when the lesson is durable.

## Who it is for

- Learners stuck on an error who need to find it themselves.
- Tutors who want the learner doing the diagnosis.
- Coding assistants asked to "help me find the bug" rather than "fix it".

## Works with

Any language and any agent. Pure guidance — no scripts, no credentials, no
network access.

## Suggested entry points

- "Help me debug this — I want to find it myself."
- "Why is this failing? Don't just tell me the answer."
- "What should I check next to find the bug?"
