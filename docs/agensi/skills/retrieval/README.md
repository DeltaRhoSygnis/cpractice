# retrieval

Turns learning-log material into **short, varied recall practice**.

Selects a small mix of recent and older meaningful topics. Prefers prediction,
debugging, comparison, and transfer over definitions. Withholds answers until
the learner commits, adjusts difficulty based on performance, and finishes with
one targeted practice action.

## Who it is for

- Learners revising a topic from a study log or session history.
- Tutors running spaced review.
- Coding assistants asked to "run a review session" on past material.

## Works with

Any language and any agent. Pure guidance — no scripts, no credentials, no
network access.

## Suggested entry points

- "Run a review session on what we covered."
- "Quiz me on this from last week."
- "Practise this topic before my test."
